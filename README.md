# calculo_numerico_ejercicios
Ejercicios de cálculo numérico con métodos iterativos, series y análisis de errores

## Guías

Cada ejercicio de las guías se encuentra en su propio archivo (`ej1.py`,
`ej2.py`, etc.) dentro de su carpeta. Por ejemplo:

```powershell
python "guia 1\ej1.py"
```

Los módulos `_metodos.py` contienen las funciones compartidas por los ejercicios
de cada guía.
